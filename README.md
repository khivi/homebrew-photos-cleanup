# homebrew-photos-cleanup

Homebrew tap for [photos-cleanup](https://github.com/khivi/photos-cleanup), a local web app for reviewing and clearing unwanted photos in the macOS Photos library.

Install with `brew tap khivi/photos-cleanup && brew install photos-cleanup`. Upgrade with `brew update && brew upgrade photos-cleanup`. The formula installs the `macos-photos-cleanup` package from PyPI into its own virtualenv; macOS only.
